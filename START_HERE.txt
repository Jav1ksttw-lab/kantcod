ПРОЗРАЧНАЯ ВАКАНСИЯ · КАНТКОД

1. Распакуйте архив и откройте терминал в папке, где лежит README.md.
2. Установите Python 3.10 или новее, если он ещё не установлен.
3. Выполните команды из раздела «Установка и проверка» в README.md.
4. Откройте учебный отчёт командой для своей системы.
   Windows: .\.venv\Scripts\python.exe -m src.cli report --demo
   macOS/Linux: python -m src.cli report --demo (после активации .venv).

Готовый учебный отчёт: data/reports/report_example.json.
Для анализа новых вакансий с ИИ запустите локальную модель по инструкции в README.md.
