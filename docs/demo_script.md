# Демонстрация «Прозрачная вакансия»

[Смотреть видео](demo.mp4).

1. Открыть терминал в корне репозитория и выполнить `python -m src.cli run --ai llamacpp --strict-ai --max 4`. Показать две страницы с живого API и число обработанных вакансий.
2. Открыть `src/analyzer.py`. Правила находят пропуски и противоречия. Модель проверяет возможные неоднозначности по всем полям карточки. Подтверждённые замечания получают `origin: "ai"`.
3. Выполнить `python -m src.cli verify --ai llamacpp --strict-ai --input data/sample/training_vacancies.json --output data/reports/report_verify.json`. Показать замечание про гибкий график, противоречие в оплате с двумя исходными значениями и карточку с пустым массивом замечаний.
4. Показать время запуска в `config/config.json` и пояснить, что при ошибке API сохраняется последний успешный отчёт.
5. Показать раздел «Почему подхожу» для вымышленного резюме и учебной вакансии повара. Модель выбирает подходящие пункты, а программа копирует их из исходных данных.
