# Как показать проект в терминале

Готовый ролик лежит в [docs/demo.mp4](demo.mp4). Для записи своим голосом хватит экрана терминала и микрофона. Увеличьте шрифт, откройте папку с проектом и подготовьте локальную модель по [README](../README.md). Цель — две минуты, лимит — три.

В примерах используется llama.cpp. Для Ollama замените `--ai llamacpp` на `--ai ollama`.

| Время | Что показать и сказать |
| --- | --- |
| 0:00–0:15 | Откройте терминал. «Мы проверяем, понятно ли в карточке описаны условия работы, и готовим вопросы работодателю». |
| 0:15–0:40 | Выполните `python -m src.cli run --ai llamacpp --strict-ai --max 4`. Покажите число загруженных страниц, количество вакансий и путь к JSON. Паузу ожидания можно вырезать. |
| 0:40–1:05 | Выполните `python -m src.cli verify --ai llamacpp --strict-ai --input data/sample/training_vacancies.json`. Покажите результат проверки локального файла. Скажите, что этот же режим принимает набор жюри. |
| 1:05–1:25 | Выполните `python -m src.cli report --file data/reports/report_verify.json --id train-001`. Покажите «Гибкий график» и вопрос о днях и часах. Объясните, что модель оставила вопрос после проверки всей карточки. |
| 1:25–1:40 | Откройте `train-003` той же командой. Покажите суммы «до 30 000» и «40000» из разных полей. Это противоречие нашли правила. |
| 1:40–2:00 | Откройте черновик вымышленного резюме в терминале и покажите раздел «Почему подхожу». Модель выбирает только пункты, которые уже есть в резюме. |

Сделайте короткую пробную запись и проверьте слышимость голоса. Для записи подойдёт OBS Studio или встроенная запись экрана. Экспортируйте MP4 и проверьте воспроизведение по публичной ссылке.
