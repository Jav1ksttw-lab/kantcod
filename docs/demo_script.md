# Как записать демо своим голосом

Хватит записи экрана и микрофона. Возьмите OBS Studio на Windows/Linux или встроенную запись экрана на macOS. Поставьте разрешение 1920×1080, увеличьте шрифт в терминале и закройте окна с токенами и уведомлениями. Цель — уложиться в две минуты, лимит по заданию — три.

## Перед записью

Установите зависимости и запустите модель по [инструкции](../README.md). Сделайте пробный прогон, чтобы модель успела загрузиться. Из корня проекта откройте интерфейс отдельной командой.

```sh
python -m src.cli view --demo
```

В браузере откройте `http://127.0.0.1:8765`. В терминале подготовьте команду рабочего запуска. Если будете показывать Ollama, замените `llamacpp` на `ollama`.

```sh
python -m src.cli run --ai llamacpp --strict-ai --max 4
```

## План на две минуты

| Время | Что сделать и что сказать |
| --- | --- |
| 0:00–0:15 | Откройте список вакансий. «Мы помогаем редактору понять, что уточнить у работодателя, чтобы соискателю были ясны условия». |
| 0:15–0:40 | Покажите команду `run` и её вывод после выполнения. «Это живые вакансии Калининградской области. Для короткого показа взяли четыре карточки с двух страниц». Если ожидание долгое, вырежьте паузу. |
| 0:40–1:05 | Щёлкните по вакансии помощника воспитателя. Покажите «Гибкий график» и вопрос о днях, часах и сменах. «Модель проверяет контекст всей карточки и решает, стоит ли оставить этот вопрос». |
| 1:05–1:25 | Откройте повара и покажите две разные суммы. Затем выберите «Без замечаний». «Противоречие в оплате нашли правила. Карточка без замечаний тоже попадает в отчёт». |
| 1:25–1:45 | Нажмите «Скачать JSON». Покажите команду `verify` из README и расскажите, что жюри может запустить её на своём файле с локальной моделью. |
| 1:45–2:00 | Если хватает времени, покажите раздел «Почему подхожу» в черновике резюме. «Модель выбрала относящиеся к вакансии пункты из вымышленного резюме». |

Запишите 10 секунд и прослушайте голос перед основным дублем. После записи обрежьте паузы и экспортируйте MP4. В OBS запись можно сохранить в MKV и затем выбрать **File → Remux Recordings**, чтобы получить MP4. Замените `docs/demo.mp4` или добавьте публичную ссылку в README. Проверьте воспроизведение в приватном окне, как если бы видео открыло жюри.
